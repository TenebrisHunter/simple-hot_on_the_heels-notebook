--- ЦЕЛЬ ---

Дать пользователю напоминание о необходимости записать
прошедшие занятия. Приложение работает в трее и периодически
показывает системное уведомление.

==================================================================
  1. ТРЕЙ
==================================================================

Что:
  - Иконка приложения в системном трее (рядом с часами).
  - При закрытии окна (крестик) — приложение НЕ закрывается,
    а сворачивается в трей.
  - Меню трея (правый клик):
    * «Открыть»      — разворачивает окно.
    * «Настройки»    — открывает окно на вкладке настроек.
    * «Выход»        — полное закрытие приложения.

Настройки:
  - «Сворачивать в трей» — вкл / выкл.
    - Если выкл — крестик ЗАКРЫВАЕТ приложение.
    - Если вкл  — крестик СВОРАЧИВАЕТ в трей.

По умолчанию: выкл (чтобы не пугать пользователя).
Когда включается — показываем уведомление:
  «Приложение будет работать в трее. Для полного выхода
   используйте меню трея → Выход.»

Реализация:
  - Tauri 2 feature: "tray-icon".
  - При закрытии окна — обработчик CloseRequested.
  - Если tray_enabled — window.hide() вместо close().

==================================================================
  2. НАПОМИНАНИЯ
==================================================================

Что:
  - В определённое время (например, 19:00) — системное
    уведомление.
  - Текст: «Не забудь записать прошедшие занятия».
  - Клик по уведомлению → открывается окно → вкладка «Занятия».

Настройки:
  - «Напоминать» — вкл / выкл.
  - «Время напоминания» — по умолчанию 19:00 (можно менять).

По умолчанию: выкл.

Условия показа:
  - Если включено.
  - Если приложение запущено (в трее).
  - Если сейчас — заданное время (в течение минуты).
  - Если сегодня уведомление ещё НЕ показывалось.
    (Чтобы не спамить — одно напоминание в день.)

Реализация:
  - Tauri plugin: notification.
  - Фоновая задача (tokio) — проверяет время каждую минуту.
  - Флаг last_notified_date — в config.json.
  - Если уведомление уже показывалось сегодня — не показываем.

==================================================================
  3. ХРАНЕНИЕ НАСТРОЕК
==================================================================

Всё в config.json (%APPDATA%\simple-hot_on_the_heels-notebook\):

  {
    "data_dir": "...",
    "tray_enabled": true,
    "notifications_enabled": true,
    "notification_time": "19:00",
    "last_notified_date": "2026-10-14"
  }

==================================================================
  4. КРОССПЛАТФОРМЕННОСТЬ
==================================================================

  - Уведомления через tauri-plugin-notification:
    * Windows — Toast Notifications.
    * macOS — Notification Center.
    * Linux — libnotify / D-Bus.
    * Android / iOS — нативные (потом).

  - Трей — Tauri 2 feature "tray-icon":
    * Windows — системный трей.
    * macOS — menu bar.
    * Linux — AppIndicator.

==================================================================
  5. ЧТО НЕ ДЕЛАЕМ (пока)
==================================================================

  - Email-уведомления.
    Причина: SMTP, пароли, OAuth, спам-фильтры.
    Плюс: работает без запущенного приложения.
    Решение: отложить. Может быть, в v62+.

  - Расписание занятий по группам.
    Причина: сложно (дни недели, каникулы, переносы).
    Решение: отложить. Одно время напоминания на всё.

  - Отдельные настройки напоминаний для каждой группы.
    Причина: усложнение UI без явной выгоды.
    Решение: одно время для всего приложения.
