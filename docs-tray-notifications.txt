--- ЦЕЛЬ ---

Дать пользователю инструмент для создания собственных
напоминаний. НЕ пытаемся угадывать расписание занятий —
даём конструктор, пользователь сам настраивает.

==================================================================
  1. ТРЕЙ
==================================================================

Что:
  - Иконка приложения в системном трее (рядом с часами).
  - При закрытии окна (крестик) — приложение НЕ закрывается,
    а сворачивается в трей (если включено).
  - Меню трея (правый клик):
    * «Открыть»      — разворачивает окно.
    * «Настройки»    — открывает окно на вкладке настроек.
    * «Выход»        — полное закрытие приложения.

Настройки:
  - «Сворачивать в трей» — вкл / выкл.
    - Если выкл — крестик ЗАКРЫВАЕТ приложение.
    - Если вкл  — крестик СВОРАЧИВАЕТ в трей.

По умолчанию: выкл.

==================================================================
  2. НАПОМИНАНИЯ — КОНСТРУКТОР
==================================================================

Идея:
  Пользователь сам создаёт список напоминаний. Каждое:
    - Время (HH:MM)
    - Дни недели (пн, вт, ср, чт, пт, сб, вс — галочки)
    - Вкл / выкл (переключатель)
    - Текст (опционально, по умолчанию «Не забудь записать
      прошедшие занятия»)

Примеры использования:
  - «Каждый день в 19:00» — все дни, 19:00.
  - «Рабочие дни в 19:00» — пн-пт, 19:00.
  - «Утром и вечером» — два напоминания: 08:00 и 19:00.
  - «По будням утром» — пн-пт, 08:00.
  - 30 напоминаний на каждое занятие — тоже можно.

UI:
  - Раздел «Напоминания» в настройках.
  - Список напоминаний:
    ┌──────────────────────────────────────┐
    │ [✓] 19:00  Пн Вт Ср Чт Пт  [🗑️]     │
    │ [✓] 08:00  Пн Ср Пт        [🗑️]     │
    │ [ ] 14:00  Сб Вс           [🗑️]     │
    │                                       │
    │ [+ Добавить напоминание]              │
    └──────────────────────────────────────┘
  - Галочка слева — вкл/выкл конкретного напоминания.
  - Клик по времени — редактирование.
  - Клик по дням — переключение.
  - Кнопка [🗑️] — удалить.
  - Кнопка [+ Добавить] — новое напоминание.
  - Кнопка «Свернуть в трей» — отдельно (общая настройка).

Хранение (config.json):
  {
    "data_dir": "...",
    "tray_enabled": true,
    "reminders": [
      { "id": "1", "time": "19:00", "days": [1,2,3,4,5], "enabled": true },
      { "id": "2", "time": "08:00", "days": [1,3,5], "enabled": true },
      { "id": "3", "time": "14:00", "days": [6,7], "enabled": false }
    ],
    "last_notified": {
      "1": "2026-10-14",
      "2": "2026-10-14"
    }
  }

  days: 1 = Пн, 2 = Вт, 3 = Ср, 4 = Чт, 5 = Пт, 6 = Сб, 7 = Вс.
  last_notified: чтобы не показывать одно и то же
    напоминание дважды в день.

Логика работы:
  - Фоновая задача проверяет каждую минуту:
    * Сейчас время = времени напоминания?
    * Сегодня этот день входит в days?
    * enabled = true?
    * last_notified[id] ≠ сегодня?
  - Если всё ок — показываем уведомление,
    записываем last_notified[id] = сегодня.

Реализация:
  - Tauri plugin: notification.
  - Фоновая задача (tokio) — проверка каждую минуту.
  - Сохранение reminders в config.json.

По умолчанию: пустой список (нет напоминаний).

==================================================================
  4. КРОССПЛАТФОРМЕННОСТЬ
==================================================================

  - Уведомления через tauri-plugin-notification:
    * Windows — Toast Notifications.
    * macOS — Notification Center.
    * Linux — libnotify / D-Bus.

  - Трей — Tauri 2 feature "tray-icon":
    * Windows — системный трей.
    * macOS — menu bar.
    * Linux — AppIndicator.

==================================================================
  5. ЧТО НЕ ДЕЛАЕМ
==================================================================

  - Email-уведомления.
    Причина: SMTP, пароли, OAuth, спам-фильтры.
    Решение: отложить.

  - Расписание занятий по группам.
    Причина: усложнение.
    Решение: НЕ нужно — пользователь сам создаёт напоминания.

  - Привязка напоминаний к группам/занятиям.
    Причина: минимализм.
    Решение: НЕ нужно — напоминания независимы.
