============================================================
  ⚠️  ВАЖНО: ПЕРСОНАЛЬНЫЕ ДАННЫЕ
============================================================

Приложение хранит все данные ЛОКАЛЬНО на вашем компьютере,
в папке data/. Данные НЕ передаются в интернет и НЕ
отправляются разработчику.

НО: данные хранятся В ОТКРЫТОМ ВИДЕ — в обычных текстовых
файлах .txt. Любой, у кого есть доступ к вашему компьютеру
и папке data/, сможет их прочитать.

Внося в программу персональные данные других людей
(ФИО учеников, причины пропусков и т.п.), вы делаете это
ОСОЗНАННО и ПОД СВОЮ ОТВЕТСТВЕННОСТЬ.

Убедитесь, что:
  - у вас есть право хранить эти данные;
  - ваш компьютер защищён паролем;
  - папка data/ не доступна посторонним.

============================================================
  УСТАНОВКА (С УСТАНОВЩИКОМ)
============================================================

1. Скачай установщик из раздела Releases на GitHub:
   - simple-hot_on_the_heels-notebook_x.x.x_x64-setup.exe
   - или simple-hot_on_the_heels-notebook_x.x.x_x64_en-US.msi
2. Запусти .exe или .msi.
3. Следуй инструкциям установщика.
4. Запусти приложение из меню «Пуск».

============================================================
  ЗАПУСК БЕЗ УСТАНОВЩИКА (ПОРТАТИВНАЯ ВЕРСИЯ)
============================================================

Если вы не хотите устанавливать приложение, можно
запустить его напрямую — без установки.

ВАРИАНТ А: запуск готового .exe из сборки

1. Скачай архив с портативной версией (если он есть в Releases).
2. Распакуй архив в любую папку (например, на Рабочий стол).
3. Запусти simple-hot_on_the_heels-notebook.exe.
4. Рядом с .exe создастся папка data/ — там будут данные.

ВАРИАНТ Б: сборка из исходников

Требуется:
  - Node.js 18+
  - pnpm
  - Rust (rustup)
  - MSVC (Visual Studio Build Tools с C++)

Шаги:

1. Склонируй репозиторий:
   git clone https://github.com/TenebrisHunter/simple-hot_on_the_heels-notebook.git

2. Перейди в папку:
   cd simple-hot_on_the_heels-notebook

3. Установи зависимости:
   pnpm install

4. Собери релиз:
   pnpm tauri build

5. Готовый .exe будет в:
   src-tauri/target/release/simple-hot_on_the_heels-notebook.exe

6. Скопируй .exe в удобное место и запускай.
   Рядом создастся папка data/.

ВАРИАНТ В: запуск в режиме разработки

1. Склонируй репозиторий (см. выше).
2. pnpm install
3. pnpm tauri dev
4. Приложение откроется в окне Tauri.

============================================================
  ДАННЫЕ
============================================================

Данные хранятся в папке data/ рядом с приложением:
  data/groups/   — группы и занятия
  data/trash/    — корзина (30 дней)
  data/imports/  — папка для импорта

При переносе .exe в другое место — папка data/
перемещается вместе с ним (или создаётся заново).
