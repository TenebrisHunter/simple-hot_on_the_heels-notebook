 ============================================================
  ⚠️  重要：个人数据
============================================================

应用将所有数据本地存储在您电脑的 data/ 文件夹中。
数据不会发送到互联网，也不会发送给开发者。

但数据以明文形式存储 —— 在普通的 .txt 文件中。
任何能访问您电脑和 data/ 文件夹的人都可以读取。

在程序中录入他人的个人数据（学生姓名、缺勤原因等）时，
您是知情且自行承担责任的。

请确保：
  - 您有权存储这些数据；
  - 您的电脑已设置密码保护；
  - data/ 文件夹不对他人开放。

============================================================
  安装（使用安装程序）
============================================================

1. 从 GitHub Releases 下载安装程序：
   - simple-hot_on_the_heels-notebook_61.0.0_x64-setup.exe
   - 或 simple-hot_on_the_heels-notebook_61.0.0_x64_en-US.msi
2. 运行 .exe 或 .msi。
3. 按照安装程序提示操作。
4. 从「开始」菜单启动应用。

============================================================
  免安装运行（便携版）
============================================================

如果您不想安装应用，可以直接运行。

方式 A：运行构建好的 .exe

1. 下载便携版压缩包（如果 Releases 中有）。
2. 解压到任意文件夹（例如桌面）。
3. 运行 simple-hot_on_the_heels-notebook.exe。
4. 在 .exe 旁边会创建 data/ 文件夹 —— 数据保存在那里。

方式 B：从源码构建

需要：
  - Node.js 18+
  - pnpm
  - Rust (rustup)
  - MSVC（含 C++ 的 Visual Studio Build Tools）

步骤：

1. 克隆仓库：
   git clone https://github.com/TenebrisHunter/simple-hot_on_the_heels-notebook.git

2. 进入文件夹：
   cd simple-hot_on_the_heels-notebook

3. 安装依赖：
   pnpm install

4. 构建发布版：
   pnpm tauri build

5. 生成的 .exe 位于：
   src-tauri/target/release/simple-hot_on_the_heels-notebook.exe

6. 将 .exe 复制到任意位置并运行。
   旁边会创建 data/ 文件夹。

方式 C：开发模式运行

1. 克隆仓库（见上）。
2. pnpm install
3. pnpm tauri dev
4. 应用将在 Tauri 窗口中打开。

============================================================
  数据
============================================================

数据存储在应用旁边的 data/ 文件夹中：
  data/groups/   —— 小组和课程
  data/trash/    —— 回收站（30 天）
  data/imports/  —— 导入文件夹

将 .exe 移动到其他地方时 —— data/ 文件夹
会随之移动（或重新创建）。
